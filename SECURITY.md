# Security Policy

This policy applies to every repository in the `aziontech` organization that does not publish its own `SECURITY.md`.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.**

Send an email to **security@azion.com** with:

- The affected repository, and the version, tag or commit
- Type of vulnerability and its impact
- Step-by-step instructions to reproduce
- Proof-of-concept or exploit code, if available

## Response Timeline

| Stage | SLA |
|-------|-----|
| Acknowledgment | 2 business days |
| Status update | 5 business days |
| Fix or mitigation | Based on severity |

## Vulnerability Management

When we receive a vulnerability report:

1. We acknowledge receipt within 2 business days
2. We confirm the issue and determine the affected versions
3. We prepare a fix for all supported versions
4. We release the fix and publish a security advisory

## Acknowledgments

We appreciate responsible disclosure and will acknowledge security researchers who report valid vulnerabilities.
